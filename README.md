#ReelDeal — ريل ديل
A video-first e-commerce marketplace where every product is a short reel (15–30 seconds), not a static page. Buyers swipe through product reels — TikTok-style — and purchase directly without ever opening a product page. Sellers upload their own video or let the AI generate a professional reel with Arabic/English voiceover from product photos and a description.
Built for the GCC market with native Arabic (RTL) and English (LTR) support, Stripe Connect escrow payments, and an n8n automation layer that filters listings, checks prices against the market, and handles reel generation pipelines before anything goes live.
Stack: Laravel 11 · Vue 3 · Pinia · Stripe Connect · Bunny.net CDN · n8n · Anthropic Claude API
Status: 🚧 Active development — V1 MVP
